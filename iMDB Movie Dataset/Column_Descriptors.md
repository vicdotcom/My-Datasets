### iMDB Top 100 Movies Dataset

Provides information on the top 100 highest rated films on iMDB. Obtained from [here](https://www.kaggle.com/datasets/shreyasur965/imdb-top-100-movies-dataset?resource=download).

| Field       | Type                  | Description                                                                 |
| :---------- | :-------------------- | :-------------------------------------------------------------------------- |
| `rank`      | Integer               | Value representing the position of the movie in the IMDb top 100 list (1-100). |
| `title`     | String                | The title of the movie.                                                     |
| `description`| String                | A brief synopsis of the movie's plot.                                       |
| `genre`     | String or List        | Genres associated with the movie (e.g., "Drama, Action").                   |
| `rating`    | Float                 | The IMDb rating of the movie (typically on a scale of 1 to 10).             |
| `year`      | Integer               | The release year of the movie.                                              |
